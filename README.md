# מדד הכנסת

כלי שקיפות שנבנה על נתוני ה-OData הרשמיים של הכנסת. כל שדה כאן
נגזר מרשומה רשמית — אין דירוג, ציון או פרשנות, רק ספירה ותאריכים.

## העלאה ל-GitHub Pages

1. `git init && git add . && git commit -m "מדד הכנסת"`
2. פתחי מאגר חדש ב-GitHub ודחפי אליו.
3. Settings ← Pages ← Source: `main` / `root`.
4. האתר יעלה ב-`https://<שם>.github.io/<מאגר>/`

שני קבצי ה-DB מתחת ל-100MB, אז אין צורך ב-Git LFS.

## מבנה

| קובץ | גודל | תוכן |
|---|---|---|
| `index.html` | 32KB | הממשק |
| `knesset_web.db` | 78MB | 783,822 שורות הצבעה, כנסתות 22–25 |
| `knesset_extra.db` | 21MB | 42,894 פרוטוקולי ועדות, 2,806 תקנות |
| `candidates.json` | 327KB | 208 מועמדים ב-34 רשימות |
| `people_index.json` | 168KB | 1,103 אנשים שכיהנו אי פעם |
| `history/*.json` | 6.5MB | קובץ לכל אדם, נטען בלחיצה |

## שני מסכים שכדאי להכיר

**הסל שלי** — בלשונית *הצבעות* מסננים לפי נושא ותאריך, מוסיפים חוקים
בכפתור `+`, ואז בלשונית *הסל שלי* מסמנים בכל אחד "אני בעד" או "אני נגד".
המערכת מחשבת לכל ח"כ כמה פעמים הצביע כמוך, ומציגה רצועה שבה כל ריבוע
הוא חוק אחד. הסל נשמר בדפדפן בין ביקורים.

**תמונת מצב** — מה שהאנשים שרצים היום עשו בכנסת: כמה מכל רשימה כיהנו
בעבר, כמה הצעות חוק יזמו, כמה מהן עברו, וכמה כהונות כיו"ר ועדה.

## מקורות

- **הכנסת** — `knesset.gov.il/OdataV4/ParliamentInfo`. ח״כים, סיעות,
  ועדות, הצעות חוק, הצבעות, שאילתות, סדר יום.
- **ויקיפדיה** — רקע על מועמדים שאין להם רקורד בכנסת. מסומן ככזה.
- **רשימות המועמדים** — נכון ל-5.9.2026, ומקורן בדיווח ולא בוועדת
  הבחירות. ההגשה הרשמית מסתיימת ב-8.9. אחרי אותו מועד יש להריץ
  את `candidates.py` מחדש מול `data.gov.il`.

## סימון אמינות

לכל מועמד יש תג:

- **רקורד בכנסת** — כיהן ב-22–25. יש הצבעות, ועדות ותפקידים.
- **ויקיפדיה** — לא כיהן, אבל יש ערך. תקציר, לידה, שיוכים.
- **ללא מקור** — לא נמצא באף מקור. או פנים חדשות או שם שגוי ברשימה.

ההבחנה גלויה בממשק בכוונה. כלי שנועד לעזור להחליט למי להצביע
חייב לומר מה הוא יודע ומה לא.

## מה חסר

- נוכחות פר ישיבת ועדה — לא מתפרסמת כנתון גולמי, רק בגוף הפרוטוקול.
- קדנציות 1–21 בהצבעות. הן קיימות ב-DB המלא (904MB) ולא בגרסת האתר.
- תפקידים לפני הכנסת — קיימים חלקית דרך שיוכי ויקיפדיה.
